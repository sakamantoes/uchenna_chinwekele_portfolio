# VS Code Portfolio - Developer Terminal Edition

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![VS Code Inspired](https://img.shields.io/badge/UI-VS%20Code-0078d4)

A professional, interactive portfolio website inspired by the Visual Studio Code interface. Features a side navigation bar, an integrated terminal that responds to commands, and a clean developer-focused design.

![Portfolio Preview](https://via.placeholder.com/800x450?text=VS+Code+Portfolio+Preview)

## ✨ Features

### 🎨 Visual Studio Code Aesthetic
- **Activity Bar** - Vertical navigation with icons (About, Skills, Projects, Contact)
- **Title Bar** - Authentic VS Code styling with file badges
- **Workbench Layout** - Content area + integrated terminal panel
- **Dark Theme** - Professional `#1e1e1e` background with proper syntax highlighting colors

### 🖥️ Integrated Terminal
- Interactive command-line interface within the portfolio
- Real-time command execution
- Collapsible terminal panel (just like VS Code)
- Custom commands to navigate and interact with the portfolio

### 📱 Fully Responsive
- Adapts to desktop, tablet, and mobile screens
- Touch-friendly navigation icons
- Responsive card grids and layouts

### 🧭 Side Navigation
- Persistent activity bar on the left
- Visual indicators for active sections
- Hover effects and smooth transitions

## 🚀 Available Terminal Commands

| Command | Action |
|---------|--------|
| `help` | Display all available commands |
| `about` or `home` | Navigate to About section |
| `skills` | Navigate to Skills section |
| `projects` | Navigate to Projects section |
| `contact` | Navigate to Contact section |
| `date` | Show current system date and time |
| `clear` | Clear terminal output |
| `nav [section]` | Navigate to specific section (home/skills/projects/contact) |

## 🛠️ Tech Stack

- **HTML5** - Semantic structure
- **CSS3** - Custom properties, flexbox, grid, animations
- **JavaScript (ES6+)** - DOM manipulation, event handling, terminal logic
- **Font Awesome 6** - Icons for navigation and UI elements
- **Google Fonts (Inter)** - Modern, clean typography
